# QB

Закупки для HoReCa в Армении: оптовики, магазины и производители продают продукты и расходники,
кафе и рестораны заказывают у всех в одной корзине и могут торговаться.

Работает на **[qb.ayoo.space](https://qb.ayoo.space)**. Интерфейс на армянском, русском и английском.

## Что умеет

- **Каталог без входа** — поиск на трёх языках и латиницей («panir» находит «պանիր» и «сыр»).
- **Карточка товара** — фото, оптовые цены, минимальная партия, характеристики по категории (для мяса — охлаждённое
  или замороженное, для сыра — молоко и жирность), производитель и страна, хранение и срок годности, сертификаты
  и декларации ЕАЭС.
- **Одна корзина на нескольких поставщиков** — минимальный заказ, доставка и дата по каждому, отправка одной кнопкой.
- **Торг** — покупатель предлагает цену, продавец принимает, отклоняет или называет свою. Автопилот продавца
  в процентах с примерами ответов, карточка клиента, подсказки обеим сторонам.
- **Заказ до приёмки** — подтверждение, доставка, приёмка, отметка об оплате, чат по заказу.
- **Документы по законам РА** — счёт, накладная и акт выпускаются сами, номера e-документов КГД, печать пачкой.
- **Компании** — регистрация по ИНН, проверка оператором, одна компания может и покупать, и продавать.
- **Уведомления** — колокольчик, почта и Telegram.
- **Кабинет продавца** — товары, оптовые цены, условия доставки, загрузка прайса из Excel/CSV (в том числе выгрузки ArmSoft).

Стек: FastAPI, PostgreSQL, Redis, React + Vite (PWA), Docker Compose.

## Быстрый старт

```bash
cp .env.example .env
docker compose up -d --build
docker compose run --rm api python -m app.seed
open http://localhost:8090
```

Каталог открыт без входа. Войти — кодом на почту (в разработке код показывается на экране) или кнопками
демо-пользователей (работает, пока в `.env` стоит `DEV_LOGIN=true`). Google и Telegram включаются ключами в `.env`.
